# Punkies y Cerebro — web de prueba

Esta versión incluye logo original enviado por la banda, fondo de pantano de prueba y diseño adaptable a móviles.

## Para publicar en GitHub Pages

1. Abre tu repositorio `punkiesycerebro/punkiesycerebro.github.io`.
2. Selecciona **uploading an existing file**.
3. Extrae este ZIP. **Sube el contenido de la carpeta** (index.html, styles.css, script.js, content, assets y .pages.yml), nunca el ZIP directamente.
4. Haz clic en **Commit changes**.
5. Ve a Settings → Pages → Deploy from a branch → main → /(root) y guarda.

**Importante:** todo está en modo prueba: sin fechas, precios, enlaces o datos comerciales inventados. Las fotos y portadas finales están pendientes.
